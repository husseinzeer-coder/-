# شعبة الحفاظ — نسخة التطوير بالقالب الثالث

هذه حزمة موقع HTML تعمل على GitHub Pages أو محليًا بواسطة Live Server. تضم القالبين السابقين من حزمة V2 التجريبية، وتضيف **القالب الثالث: تقرير اللقاء**.

## كيفية التشغيل
1. فك ZIP.
2. افتح المجلد في VS Code ثم افتح `index.html` بواسطة Live Server (أو انشر الملفات في جذر الفرع `v2-development` في GitHub).
3. من قائمة القوالب اختر «القالب الثالث — تقرير اللقاء»؛ ستُفتح `meeting.html`.
4. عدّل العنوان واليوم والتاريخ والمعلومات الثلاث، وحقول أسماء الأعمدة الثلاثة.
5. تظهر أسماء الطلاب الـ17 من الكشف المرجعي مبدئيًا، ويمكن تعديلها أو حذفها وإضافة طلاب حتى 25؛ لن تظهر الصفوف بلا أسماء في الصورة، وتتمدد الصفوف الظاهرة حتى ارتفاع مناسب.
6. ارفع الشعار؛ تُقص الصورة تلقائيًا في واجهة المعاينة ضمن دائرة الشعار. حدد «غائب» للصف المدمج، واختر الانضباط ولون الجائزة.
7. اضغط تنزيل صورة PNG.

**مهم:** لا تغيّر إعداد GitHub Pages إلى فرع التطوير؛ إبقاؤه على `new-design` يحافظ على الموقع المنشور. جميع بيانات القالب الثالث تُحفظ محليًا في الجهاز والمتصفح المستخدم، ولا تُزامن بين الأجهزة. حذف بيانات المتصفح يمسح الحفظ المحلي.

## البنية
- `index.html`, `app.js`, `report.js`, `templates.js`, `students.js`, `style.css`: برنامج القالبين السابقين.
- `meeting.html`: واجهة القالب الثالث وكود الرسم الخاص بجدول اللقاء (المنظومة تختلف وظيفيًا عن تسميع القالبين السابقين).
- `assets/meeting-background.png`: صورة القالب الثالث الأصلية المرفقة من المستخدم، دون النصوص.
- `assets/background.png`, `assets/background-12.png`: خلفيات القالبين السابقين.

## الملاحظات
- هذه نسخة للتجربة الأولية. فُحصت صياغة JavaScript، لكن لم يُجر اختبار آلي كامل في متصفح حقيقي على هذا الجهاز.
- لا تستبدل بها نسخة النشر قبل اختبار الإدخال والحفظ والتنزيل والتحقق من مكان الجدول على الهاتف.
- ألوان «منضبط» أخضر و«غير منضبط» أحمر، و«غائب» يغطي الخانات ما عدا رقم الصف.
- تسميات السورة والآيات والملاحظات قابلة للتعديل من إعدادات القالب الثالث.
